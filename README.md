# 🚀 DIO_GEN_AI_DADOS

Este repositório reúne todos os projetos, desafios e anotações desenvolvidos por mim durante o BootCamp **GenIA & Dados**, promovido pela **DIO (Digital Innovation One)** em parceria com o **Bradesco**.

O objetivo principal deste repositório é registrar minha evolução ao longo do bootcamp, reunindo atividades práticas, desafios de programação, documentação e projetos voltados para **Python, Dados e Inteligência Artificial Generativa**.

---

## 📌 Sobre o BootCamp

O BootCamp **GenIA & Dados** foi uma jornada focada no desenvolvimento de habilidades essenciais para o mercado, abordando:

- Fundamentos de programação com **Python**
- Lógica de programação aplicada na prática
- Manipulação e estruturação de dados
- Boas práticas de desenvolvimento
- Versionamento com Git e GitHub
- Criação e organização de documentação com Markdown
- Introdução ao universo de **IA Generativa**

---

## 🗂️ Estrutura do repositório

O repositório está organizado por desafios e projetos desenvolvidos ao longo do BootCamp:

### 📁 Desafio_3_Python
Contém exercícios e desafios voltados para lógica de programação com Python, incluindo:
- Manipulação de dados

Inclui também arquivos `.py` e documentação em README.
