# SQL com Microsoft Copilot

Projeto desenvolvido durante o curso 
"Utilizando Microsoft Copilot para escrever consultas SQL".

## 📂 Estrutura do projeto

- `assets/` – Imagens utilizadas no projeto
- `db_scripts/tables/` – Criação das tabelas
- `db_scripts/seeds/` – Scripts de carga inicial de dados
- `db_scripts/views/` – Views SQL
- `prompts/` – Prompt utilizado com o Microsoft Copilot
